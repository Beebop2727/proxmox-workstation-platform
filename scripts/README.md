# Scripts

> [!NOTE]
> **Archived project area**
>
> Automation was planned for later phases of the Proxmox Workstation Platform but was not implemented before the project was shelved on **4 September 2026**.

This directory was originally intended to contain automation for the Proxmox workstation and supporting infrastructure.

Planned tooling included:

* VM start / stop helpers
* Backup automation
* Wake-on-LAN and local power-control helpers
* Infrastructure health checks
* Dashboard integration
* Firewall verification
* WireGuard verification
* Proxmox workflow automation

These scripts were not developed before the architecture was retired.

The directory is retained to preserve the original repository structure and development plan.

Where relevant, automation concepts may be reconsidered in the successor **Ryoku + KVM/QEMU + GPU passthrough** project rather than being implemented against the retired Proxmox environment.
